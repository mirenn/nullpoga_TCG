# Nullpoga TCG (ヌルポガ TCG) - 5レーン・リアルタイムカードバトル

> 5レーンのフィールドにリアルタイムでカードを展開し、敵拠点を攻め落とすリアルタイムカードバトル（タワーオフェンス型デジタルカードゲーム）。

---

## 🎮 ゲーム概要

プレイヤーとCPUがリアルタイムにマナを蓄積しながら、手札のカードを5つのレーンに配置して戦います。  
召喚されたユニットは自動で前進・交戦し、敵陣最奥の拠点を破壊（HP 20 → 0）した側が勝利となります。

### コアルール

1. **5レーン・フィールド**
   - 画面は縦方向に5つのレーン（Lane 1〜5）で構成されています。
   - 自陣（画面下側）から出撃したユニットは敵陣（画面上側）へ向かって前進します。
   - 敵ユニットと遭遇（射程内）すると交戦状態に入り、互いに攻撃を行います。
   - 敵陣最奥に到達したユニットは敵拠点へ直接ダメージを与えます。

2. **リアルタイム・マナシステム**
   - 時間経過でリアルタイムにマナが回復します（最大10マナ）。
   - ゲーム内UIでマナ回復速度（ゆっくり／標準／高速／ウルトラ等）を切り替え可能です。
   - カードごとに消費マナ（コスト）が設定されています。

3. **操作体系**
   - **ドラッグ＆ドロップ**: 手札のカードを目的のレーンへ直接ドラッグして召喚。
   - **クリック / キーボード操作**: 手札をクリックまたは `1` 〜 `4` キーでカードを選択し、出撃させたいレーンをクリック。
   - **ESCキー**: 選択解除。

4. **勝利条件**
   - 相手プレイヤー（CPU）の拠点HP（20）を 0 以下に減らすと勝利。
   - 自陣の拠点HPが 0 以下になると敗北。

> **💡 移動速度の仕様と調整ガイド**:
> - **単位（%/s）**: 1秒あたりにレーン全長（0〜100%）に対して進む移動割合です。
> - **敵陣拠点までの距離**: 召喚地点（自陣 y=95 / CPU y=5）から敵陣最奥拠点（y=6 / y=94）までの前進距離は約 **89%** です。
> - **直線走破時間（敵・障害物なし時）の目安**:
>   - 速度 8.0（ネズミ）: 約 11.1秒
>   - 速度 7.0（イノシシ）: 約 12.7秒
>   - 速度 6.0（吸血コウモリ）: 約 14.8秒
>   - 速度 5.0（ネコ / 柴犬 / アサシン通常）: 約 17.8秒（アサシン疾走時 15.0: 約 5.9秒）
>   - 速度 3.5（電気クラゲ / 炎のドラゴン）: 約 25.4秒
>   - 速度 2.5（亀吉）: 約 35.6秒
> - **速度の調整方法**:
>   - **全体一括調整**: [`packages/web/src/app/useRealtimeGame.ts`](packages/web/src/app/useRealtimeGame.ts) 内の定数 `MOVE_SPEED_SCALE`（現在 `1.0`）の数値を変更することで、ゲーム全体のテンポを一括で調整できます（例: `0.7` 〜 `0.8` にすると全体が20〜30%スローペースになります）。
>   - **ユニット個別調整**: 同ファイルの `CARD_POOL` にある各カード定義の `speed` 数値を直接変更可能です。
